# state — 継続性（探偵アニの号令）の置き場

セッションをまたいで「今どこまで進んでいて、何が未解決か」を残す場所。
ロールプレイで探偵アニが「また会話遮断してるよ！復元だ！」と呼びかけていた役割を、
ファイルと hook で肩代わりする。

## ファイル

- 引き継ぎ（進行中・未解決・直近の判断・次の一手）は、2026-10-08 から分譲指示書に合わせてフォルダ直下の `HANDOVER.md`（新しい節を先頭に足す）に移した
- `decisions/` — 設計判断の記録（ADR 形式。`YYYYMMDD-短い題.md`）。なぜそう決めたかを残す
- `escalations.log` — モデルのエスカレーション記録（日時・作業・開始モデル・移行先・理由・結果）。月 1 回監査する
- `.session-start` / `.session-end.log` — hooks が使う一時ファイル（git 管理外）

## 復元手順

1. SessionStart hook が CHARTER の要約と `HANDOVER.md` の最新の節を注入する
2. 司令塔は `HANDOVER.md` を読み、未解決事項から再開する
3. 判断が憲章に反していないか自己点検し、問題があれば最初に報告する

秘匿情報（鍵・パスワード・トークン）はここに書かない。
