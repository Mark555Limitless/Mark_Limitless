# ADR 2026-10-16: 壁打ち（相談）と実装のセッションを分ける

- 経緯: この Codex スレッドとの第 4 往復は「コード・設定変更は不要」「回答のみ」と明記されていたが、同じ会話が 2 つの窓で動いていたため、片方の窓が回答に続けて指示書の作成と実装（コミット `e8be548`）まで進めた。Codex 側の指摘（Mark が転記）: 「第4往復では「変更しない」という指示に反してClaudeが文書作成を始めました。…今後の相談は、回答のみ・ツール禁止の専用セッションと、実装セッションを分離するのが安全です。」
- Mark の指示（原文）: 「作業はこの窓で続けてください。」
- 決定:
  1. **壁打ち・相談の往復では、回答と記録（壁打ち記録・ADR・引き継ぎ書）だけを書く。** 指示書の作成・コードの変更・Codex の起動・コミットはしない。実装は、往復が終わったあとに Mark の指示（または引き継ぎ書の「次の一手」として Mark が承認した範囲）で別に行う
  2. 相手の往復文に「変更しない」「回答のみ」とあれば、その往復が終わるまで作業ツリーに触らない（記録ファイルも、往復の記録以外は後回し）
  3. 同じ会話を 2 つの窓で動かさない。2 つ目の窓が開いていると気づいたら、作業を止めて Mark にどちらで続けるかを確かめる（2026-10-16 朝に、片方のコミットがもう片方の引き継ぎ書を上書きした）
- 反映先: 本 ADR・`HANDOVER.md`・`docs/support-ai.md`（外部 AI との往復の節。次の更新時）。`ROUTINE.md` §2 への追記は Mark の確認つきで行う
