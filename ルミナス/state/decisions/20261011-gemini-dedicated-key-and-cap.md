# ADR 2026-10-11: Gemini はルミナス専用の鍵、上限は 1 日 $0.25 目安

元: 分譲指示書 §3.3 の ①鍵の新規発行 と ②上限（README §11 の 6）。Mark がチャットで決めた。

## 1. 鍵 → ルミナス専用に新規発行する
- Mark の指示（原文）: 「上記1,2,3,4はそちらで作業を代行してください。」（新しい Google Cloud プロジェクトを作って鍵を作る手順）
- 実施: Google Cloud プロジェクト `Luminous`（ID `luminous-511308`・組織なし）を作り、AI Studio に読み込んだ。請求先は既存の `My Billing Account`（Tier 2・前払い）に自動で紐づいた。鍵の名前は Mark の指定で「Component for Luminous」
- 鍵の作成の最後の操作とコピーは Mark が行う（鍵の値を司令塔の画面・ログに入れない）
- 注意: 前払いの残高は fable5 の画像プロジェクトと共有。残高が尽きると両方止まる

## 2. Gemini の上限 → 1 日 $0.25 目安
- Mark の指示（原文）: 「ルミナスの Gemini は 1 日 0.25ドル目安で設定してください」
- 実施: `.env.example` の `ORCH_GEMINI_DAILY_USD_CAP=0.25`、`orch/gemini.py` の既定値も 0.25（`.env` に行が無くても同じ上限）。超えるとその日は呼ばずに「上限到達」を返す（推定費用で判定するので実額とは少しずれる）
- Jev の上限（1 日 60 回・月 $1）は変えていない
