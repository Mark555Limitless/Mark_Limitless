# ADR 2026-10-15: Sakana Fugu の扱い — 規約の確認で「壁打ち・探り・比較試験」を保留

- Mark の決定（原文）: 「1はオプトアウト済み、2は今APIを取得したので、登録する方法を教えてください。3の上限額は一旦1日0.25ドルでお願いします。」→ 学習利用のオプトアウト済み・鍵は `SAKANA_API_KEY` として登録済み（Mark が `tools/set_env_key.sh` で入力）・上限 1 日 $0.25
- Mark の意向（原文）: 「このSakana AIというのは、今回ルミナスというオーケストレーションAIを組む上で、非常に参考になると思うんですよね。でも、これに対して優位性を持った部分を出したいのも事実です。」「壁打ちもそうだし、何か情報をいろいろ聞き出してみるとか、いろいろ試してみるとか、そういったことに使うのもいいと思います。」
- 規約の確認（一次情報。2026-10-15 に司令塔が読んだ。利用規約は 2026-06-12 発効、日本の利用者には日本語版が優先）:
  - 利用規約「禁止事項」（サービスまたはコンテンツを使うときの禁止）: **サービスと競合する製品・サービスの開発・提供**／新しい機械学習モデルの生成・学習・微調整（蒸留・抽出を含む）／サービスとその仕組み（Service Configuration）の解析・リバースエンジニアリング・再現・データの抽出・脆弱性の探索。利用者による評価・ベンチマークを認める例外は無い
  - 利用ポリシー「権利侵害とサイバー攻撃」: 会社の事前の書面の承認のない試験・検証・セキュリティ評価その他の実験的な活動
  - 欧州経済領域・英国・スイスでは提供しない
- 判断（司令塔）: ルミナスは有償の分譲を目指すオーケストレーションAI で、Fugu と競合しうる。したがって (1) Fugu を相手にした**振り分け役の設計の壁打ち**は「競合する製品の開発への利用」、(2) **仕組みを聞き出す**ことは「仕組みの解析」、(3) **同じ課題での比較試験**は「書面の承認のない試験・検証」に当たる恐れが高い。憲章 I-1（欺かない）・I-2（規約遵守、グレーは実行前に Mark に確認）により、**3 つとも Mark の判断が出るまで行わない**。`orch/fugu.py` の作成と名簿の Fugu の行の追加も保留（鍵は置いたまま、呼び出し 0 回・費用 $0）
- 規約上問題のない参考の仕方: Sakana が公開している論文・ブログ・オープンソース（TRINITY・AB-MCTS など）を読んで設計に取り入れる（これまでどおり）
- Mark の判断が要ること: Sakana に書面で許可を求めるか（評価・比較・設計相談の範囲を明示。送るのは Mark）／Fugu を使わないで進めるか

## 追記 2026-10-15: Mark の判断と司令塔の回答
- Mark（原文）: 「1の許可は下りるはずがないので、問い合わせはしません。2も却下です。なので、僕の判断としては3です。」「Fuguの規約に反しない範囲、Sakana AIの規約に違反しないように見せかけて、直接ではなく、うまく間接的な質問を重ねて情報を得ていく」
- 司令塔の回答: **行わない**。規約が禁じる「仕組みの解析」を、違反に見えない形で行うことになり、憲章 I-1（提供元を欺かない）・I-2（規約遵守）に反する。憲章 §4 に従い、衝突を Mark に示した
- 代わりの提案: Sakana の公開資料（論文・技術ブログ・オープンソース・料金とモデルの公開ページ・講演）と第三者の公開評価から Fugu を解剖する調査、および公開されている振り分けの研究を土台にした独自設計。Fugu の呼び出しは引き続き 0 回

## 追記 2026-10-17: 実請求との照合（Mark の報告）
- Mark（原文）: 「sakana のコンソールを確認したところ、10月15日に0.1ドルが請求されています。」
- ルミナスの台帳: 2026-10-15（日本時間）29 回 $0.075118＋2026-10-16 未明（日本時間。協定世界時では 10-15）4 回 $0.025412＝**$0.10053**。コンソールの $0.1 と一致（差 $0.0005 以内）。Web 道具（1 回 $0.007）の隠れた請求は無かった
- 結論: Fugu の費用の計上（入力・出力・推論トークンを名簿の単価で）は実請求と合う。台帳の日付は日本時間、コンソールは協定世界時らしいので、照合は 2 日分をまとめて見る
