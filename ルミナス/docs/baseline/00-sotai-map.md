## 1. 素体の継ぎ目（入れ替えの単位）
```
 Mark（承認）
   │
 [名簿 config/roster.json] ── 役割→提供元・モデル・版・状態・送信区分・費用・戻し先
   │ 参照
 [ゲート orch/gate.py（P4・未実装）] ── 送信区分の合成チェック／宛先の許可／予算の予約と上限／失敗時は止まる
   │ 通ったものだけ
 [アダプタ] orch/gemini.py・orch/jev.py・tools/codex_*.sh（既存）・Claude のサブエージェント
   │
 [記録] data/usage.jsonl（費用台帳）・state/decisions/（判断記録）・週報・見落とし台帳
```
- モデルを入れ替えるときに変わるのは**名簿の 1 行（と、新しい提供元ならアダプタ 1 つ）だけ**にする。
- ゲートは名簿だけを見て判断する（コードに宛先・価格を書かない）。

## 3. 送信区分と合成規則
- **A**＝公開済み・匿名化した課題（外部 AI に送ってよい）。**B**＝非公開の設計・コード断片（契約で学習不使用と地域を確かめた相手だけ）。**C**＝鍵・個人情報・非公開フォルダ・利用者データ（どこにも送らない）。
- **合成**: 送る全体の区分は、部分の区分の最も重いもの。**区分の付いていない部分は C とみなす**（未知のデータは送らない）。私的語句（ローカルの絶対パス・非公開フォルダの名前・鍵の形）を含めば C。公開情報でも、組み合わせで個人や非公開事項が推定できる場合は B 以上（判定できないときは B）。
- **未知の接続**: 名簿に無い宛先・名簿で「採用」「試験中」でない宛先・リダイレクトの先が許可外の宛先は、**呼び出し前に止める**（ゲートの既定は拒否）。ただし Claude Code 自身の通信（#1）はゲートの外で、ルミナスからは制御できない。

## 4. 費用
- 費用は名簿の単価で事前に予約し、上限（金額・呼出し数・トークン・時間）のどれかで止める。**単価が不明な相手は予約できない＝呼ばない**（費用不明をゼロとしない）。契約枠（Claude・Codex）は金額に換算せず、呼出し数・時間で数える。
- 追加の API 支出は、上限が決まるまで 0 円（Mark の判断待ち）。
