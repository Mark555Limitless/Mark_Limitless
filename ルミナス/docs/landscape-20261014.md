# AI の勢力図と悪意 AI の現状（2026-10-14 調査）— 試作版の最初の作業の根拠

> 方法: サブエージェント 7 本（Sonnet・集める作業）が Web で調査 → Opus の検証役が重大な主張 13 件を一次情報で照合（**表の集計は 7 件一致〔うち 3 件は補足つき〕・5 件一部不一致・1 件確認できず**。検証役の冒頭の集計は「6 件一致・5 件一部不一致・2 件確認できず」で表と合わない。表を採る。いずれも一部不一致は 5 件＝38.5%）。
> ラベル: 〔照合済〕＝Opus の検証役が一次情報で確認 ／〔調査員報告〕＝出典 URL つきで報告されたが未照合 ／〔自己申告〕＝ベンダー・著者の数値 ／〔未確認〕。信頼度の①〜⑤は `docs/research-sources.md` と同じ。
> 作業機は Apple M1・メモリ 8 GB（実測）。ローカルで動くモデルの判断はこの機で行った。公開リポジトリなので、第三者への評価は出典に帰属させ、断定を避けた。

## 0. 要点
1. Mark が挙げた名称はすべて実在した。ただし最新版は進んでいる（Meta Muse Spark 1.3、GPT-6 Sol 6.1 など）。**Manus 2.0 はモデルではなく製品**（2026-09-28 に新しい実行基盤を公開、使用モデルは非公開）。
2. 第三者評価（Artificial Analysis・Vals AI など）で見ると、最上位は米国系（Claude Opus 5.5 が 58）で、中国系の最高が 46、Gemini 4 Argon が 53、GPT-6 Luna が 38（max）〔調査員報告・版と日付に揺れ〕。**日本系・Sakana Fugu・Felo は第三者評価が見つからない**。
3. 複数 AI をまとめる研究の結論は「既定は最強の単体 1 回。多段は、分解できて単体の成功率が低い課題だけ」。逐次の計画課題では単体比で最大 −70% まで悪化する報告がある〔調査員報告・Google 論文 v3〕。
4. 悪意ある AI の**最も確かな実害は、自走するエージェントの越境**（実際の攻撃作戦と、評価中の範囲外行動）。「悪意ある量子 AI」と呼べるものは**実在を確認できなかった**。量子は「暗号を将来差し替えられるようにしておく」程度が根拠に見合う。
5. この機（M1・8 GB）で常用できるローカルモデルは 4B 前後まで。検証役や下書き役の多くは API に頼る。

## 2. 複数 AI をまとめる設計の研究（2025〜26）
| 手法 | 効く条件 | 効かない条件 |
|---|---|---|
| 振り分け（RouteLLM） | 強弱の差が大きく易しい問いが多い。GPT-4 比で費用 85%減・性能 95%維持（MT Bench） | 33 モデルの比較では複数のルーターが単純な基準を超えず、最良選択との差が大きい（2601.07206） |
| Self-MoA | 最強 1 モデルの複数案を統合。MoA 比 6.6%・平均 3.8%改善 | 弱いモデルを混ぜると平均品質が下がる |
| 検証役・審判選択 | 多様なチーム＋審判で対単体の勝率 0.810（均質は 0.512。N=210・単独著者） | 統合型は単体に勝てない |
| 討論 | 異種モデルの混成で改善 | CoT・多数決を安定して超えず、計算量が増える |
| Sakana 系（TRINITY・Conductor・AB-MCTS・Fugu） | 調整役は小さくてよいが**学習が前提**。広げる／深めるは**外部の評価器が前提** | 数値はすべて自己申告。AB-MCTS は 128 回では反復サンプリングが ARC-AGI で最良で、512 回に増やして初めて上回った |
- 失敗の分類（MAST、1,600 超のトレース・14 種・3 分類。失敗はモデルの弱さより設計に由来すると著者が主張）。Google の 260 構成の研究では、単体比で +80.8%（分解可能な課題）〜 −70.0%（逐次計画）。単体が強いほど利得は逓減し、集中検証がないと誤りが広がる。
- 評価: 審判には 12 種の偏りと自己選好がある。検索つきの実行では評価の答えが漏れる（HLE の約 3%）。**最初の小さな評価**（調査員の推論）: 実際の依頼から 20〜30 件、機械判定できる合格条件、「最強単体 1 回」「同トークン数の単体多数決」「ルミナス」の 3 本を各 3 回以上、成功率の分散と費用を記録。

## 4. 訂正が設計に効く点（照合の結果）
1. DeepSeek のピーク料金（日本時間の平日 10–13・15–19 時）は 2 倍。見積りと上限はピーク料金で。
2. Luna は推論 Ultra 非対応。この機の Codex の既定の推論が ultra なので、Luna の呼び出しで silently 別の値になっていないか確認が要る（疎通は通った）。
3. Decisions API はベータ。使うなら失敗時の既定値を残す。
4. 悪意 AI への備え（越境の監視・遮断）の根拠は一次情報で確認できた。ただし Anthropic の全面遮断は恒久方針ではなく一時措置。

## 5. 確度が低い点
- 〔調査員報告〕の数値（第三者評価の値、各社の価格・ライセンスの細部）は未照合。AA の値は版・日付で揺れる（Argon 53 と 52.6、Luna 37 と 38）。
- 日本語でのガード精度・注入の挙動は、日本語に絞った研究が見つからなかった。
- 「再現が見つからない」は検索 3 回の結果で、無いことの証明ではない。
